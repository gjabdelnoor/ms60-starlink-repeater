# Third-party attribution

The firmware used in this project was developed by SWRT and its upstream contributors. It was downloaded unchanged from the maintainer's MS60 directory. This repository documents how we configured it and provides an original shell configuration template.

| --- | --- | --- |
| SWRT / paldier | MS60 firmware and device-specific distribution | [Maintainer's MR60/MS60 page](https://blog.paldier.com/mk6x/), [MS60 downloads](https://firmware.swrt.site/firmware/NETGEAR/MS60/) |
| SWRT Asuswrt Broadcom project | Upstream firmware project reference | [Source repository](https://github.com/SWRT-dev/asuswrt-bcm), [license](https://raw.githubusercontent.com/SWRT-dev/asuswrt-bcm/master/License) |
